# ♞ Knightfall

**An experimental chess engine and interactive search visualization platform, built from scratch in TypeScript.**

Knightfall aims to combine chess engine development with an educational environment that makes engine decision-making easier to understand.

## 🎯 Vision

Build a chess engine from scratch and eventually visualize how it thinks — from move generation and position evaluation to search algorithms and alpha-beta pruning.

## 🛠️ Tech Stack

- TypeScript
- Node.js
- Vitest

## 🚧 Current Progress

- [x] 0x88 board representation
- [x] Initial position setup
- [x] Square utilities
- [x] Position validation
- [x] Typed move representation
- [x] Basic pawn move generation
- [ ] Complete legal move generation
- [ ] Search algorithms
- [ ] Position evaluation
- [ ] Interactive search visualization

## 🚀 Getting Started

```bash
git clone https://github.com/kapilkumar27/KnightFall.git
cd KnightFall
npm install
```

Run tests:

```bash
npm test
```

Run type checking:

```bash
npm run typecheck
```
